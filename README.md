# 📍 Consulta de CEP - ViaCEP

Aplicação web para consulta de endereços via CEP utilizando a API ViaCEP.

## 🚀 Tecnologias

- **React 19** com React Compiler
- **TypeScript** para type safety
- **Zod** para validação de schemas
- **React Hook Form** para gerenciamento de formulários
- **TailwindCSS v4** para estilização
- **Vite** para build e dev server

## 📦 Instalação

```bash
npm install
npm run dev
```

## 🎯 Funcionalidades

- ✅ Busca automática de endereço ao digitar CEP
- ✅ Validação em tempo real com feedback visual
- ✅ Máscara automática no campo CEP (00000-000)
- ✅ Campos de endereço preenchidos automaticamente
- ✅ Campos readonly com navegação por teclado otimizada
- ✅ Totalmente acessível (WCAG 2.1 AA)
- ✅ Responsivo (mobile-first)

## 🧪 Build

```bash
npm run build
npm run preview
```
