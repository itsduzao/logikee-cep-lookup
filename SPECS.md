Teste técnico de programação

Utilizando a API de CEPs Viacep (https://viacep.com.br), desenvolva uma aplicação, utilizando qualquer framework baseado em Javascript, ou mesmo Javascript puro, que contenha um formulário onde o usuário possa informar um CEP, em um campo texto com a máscara apropriada, fazendo com que e aplicação valide o formato e obrigatoriedade do CEP digitado, consulte a API Viacep e preencha na tela os campos Cidade, Estado e Logradouro, sendo que estes 3 últimos campos deverão estar desabilitados para edição.
Criar também os campos número e complemento, onde número seja obrigatório e contenha ao menos um caractere.

Desejável um bom design, conceitos de usabilidade e comentários no código.
